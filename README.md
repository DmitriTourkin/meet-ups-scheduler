# Meet Scheduler

– планировщик встреч на основе горького опыта сбора расписаний друзей и коллег через Google Spreadsheets. Пет-проект решает классическую проблему «найти время, когда
все свободны» - участники проекта отмечают свою занятость в общем календаре, а не сверяют расписания вручную в переписке.

Пет-проект сделан на **FastAPI + Next.js +
PostgreSQL + Kafka**, чтобы попрактиковаться в работе c event-driven архитектурой и активными DOM-элементами.

## Возможности (v1.0)

- Создание проекта-встречи с диапазоном поиска слота и списком участников.
- Личный календарь занятости и календарь проекта с 4 статусами: свободно,
  занят, могу освободить, есть время.
- Закрашивание занятости протяжкой мыши (drag-to-paint) с батчингом
  запросов на сервер только по отпусканию кнопки мыши.
- Три режима просмотра календаря: по дням, единая сетка участники×дни
  (с опциональной мини-тепловой картой по часам) и почасовой вид.
- Светлая/тёмная тема с ручным переключателем поверх системной настройки.
- На момент выгрузки этого файла написана упрощённая сессионная аутентификация (без JWT, будет переписана): один опорный токен, на сервере хранится только его хэш.

## Стек

- **Backend**: Python, FastAPI, SQLAlchemy (async), PostgreSQL — вертикальные
  срезы по фичам (FSD)
- **Frontend**: TypeScript, Next.js (App Router), CSS Modules.
- **Инфраструктура**: PostgreSQL в Docker, Kafka для событий
